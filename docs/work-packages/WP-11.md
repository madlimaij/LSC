# WP-11 — Real-language acceptance run

- **Owner:** orchestrator, with fixes dispatched to owning agents
- **Depends on:** WP-10, WP-00, Gate G4

## Goal

Prove the MVP on the real custom language and separate input gaps from tool defects.

## Procedure

Follow `docs/ORCHESTRATION.md` §6.

## Deliverables

- `lsc compile` on the real inputs with the approved provider, exported Rule Set `1.0.0`
- Acceptance report (kept outside the repository with the real inputs) containing:
  - coverage and confidence per rule type
  - list of input gaps for the project owner
  - tool defects found and their fixes
  - engine-limitation evidence for WP-12
  - token usage and snippet-log location
- Handover of the Rule Set and `contract/rule-set.schema.json` to Legacy Navigator

## Acceptance criteria

- Every specification acceptance criterion (plan §11) is marked met or not met, with evidence
- No real-language code in the repository (checked by the reviewer)
