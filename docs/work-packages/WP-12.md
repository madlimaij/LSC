# WP-12 — Token-matcher and state-machine engines (conditional)

- **Owner:** `engine-builder`
- **Depends on:** WP-11 evidence
- **Trigger:** WP-11 records constructs that exact + regex cannot express reliably

## Goal

Add only the engine power the real language demonstrably needs (D6).

## Deliverables

- For each recorded limitation: a toylang reproduction first, then the smallest engine that handles it (token matcher before state machine)
- Contract extension by `contract-architect` as a minor contract version, with JSON Schema re-export
- Synthesis prompt update by `llm-integrator` so the model can propose the new engine

## Acceptance criteria

- Each reproduction fails before and passes after
- Existing Rule Sets remain valid under the new contract version
