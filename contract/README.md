Published contract for Legacy Navigator:

- `CONTRACT.md` — human-readable contract: versioning, Navigator mapping, validation rules JSON Schema cannot express, matching semantics, open questions.
- `rule-set.schema.json` — JSON Schema (draft 2020-12), generated by `npm run contract:export` from `src/contract/schema.ts`. Do not edit by hand.
- `fixtures/toylang.ruleset.json` — valid example Rule Set for the synthetic language `toylang`.
- `fixtures/invalid/<rule>--<variant>.json` — one file per validation rule, each failing only for that rule.

Validate a file: `npx lsc validate-ruleset <file>`.
