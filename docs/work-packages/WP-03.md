# WP-03 — Example format and the toylang fixture language

- **Owner:** `contract-architect`
- **Depends on:** WP-02
- **Owns:** `src/examples/`, `fixtures/toylang/`

## Goal

Define the one `Example` record every other module uses (plan §6), and create a synthetic language realistic enough to exercise every rule type and the common traps.

## Deliverables

- `Example` Zod schema and type: `{ id, construct, polarity, code, expected[], source }`
- Loaders for sidecar examples (`<id>.<ext>` + `<id>.expect.yaml`) and `reviews.yaml`; inline Skill examples are parsed by WP-06 but must produce this same record
- `fixtures/toylang/SPEC.md` describing toylang. Suggested shape:

  ```
  MODULE billing
  INCLUDE "common.tl"
  -- line comment
  PROC calc_total(order_id)
    READ orders WHERE id = order_id
    IF FLAG("new_pricing") THEN
      CALL apply_discount(order_id)
    ENDIF
    WRITE invoices SET total = t
    RETURN
  ENDPROC
  ENTRY nightly_billing -> calc_total
  ```

- Deliberate traps in toylang: keywords inside comments and strings, identifiers containing keywords (`RECALL_x`, `PROCESSOR`), a statement continued over two lines, nested `IF` blocks inside a `PROC`, case-insensitive keywords
- `fixtures/toylang/skills/*.md`: one Skill file per construct, written the way a real team would (prose, conventions, traps), with inline examples in the plan §6.1 format
- `fixtures/toylang/examples/`: sidecar examples, ≥ 5 positive and ≥ 2 negative per construct overall
- `fixtures/toylang/sample-repo/`: 15–30 unlabelled toylang files including traps not covered by the examples (so the review flow has something to find)
- Align `contract/fixtures/toylang.ruleset.json` (WP-02) with the final toylang syntax. It is verified automatically in WP-05, once the runner exists

## Acceptance criteria

- Loaders produce valid `Example` records from sidecars and `reviews.yaml`; malformed files give readable errors
- Every rule type in the contract has toylang positive and negative examples
- `SPEC.md` lists every trap and which example covers it
