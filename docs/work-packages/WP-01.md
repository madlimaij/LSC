# WP-01 — Project skeleton and tooling

- **Owner:** `contract-architect`
- **Depends on:** nothing
- **Owns:** repository root config, `src/cli/` bootstrap

## Goal

A buildable, testable TypeScript project that all later packages extend without touching shared files.

## Deliverables

- `package.json` (Node.js 20+ LTS, ESM (ECMAScript modules)), `tsconfig.json` (strict), lint config, Vitest config
- Scripts: `build`, `typecheck`, `lint`, `test`
- Dependencies installed up front: `zod`, `re2`, `yaml`, `commander`, `fast-glob`, `unified` + `remark-parse` (Markdown), `@anthropic-ai/sdk`; dev: `typescript`, `vitest`, `eslint`, `tsx`
- `bin` entry `lsc`
- `src/cli/index.ts` that auto-registers every module in `src/cli/commands/` exporting `{ name, description, configure(cmd) }`
- One sample command `lsc version`
- Empty folders from plan §7 with a `README.md` each stating the owner
- `docs/progress.md` with a status table of all work packages; `docs/DECISIONS.md` with D1–D9 copied from the plan
- `.gitignore` including `.lsc/`, `out/`, and any `LSC_REAL_INPUTS` path convention

## Acceptance criteria

- `npm run typecheck`, `npm run lint`, `npm test` pass on a fresh clone
- `npx lsc version` prints the package version
- Adding a file to `src/cli/commands/` adds a command without editing any other file (proved by a test)
- `re2` installs and a smoke test compiles and runs one RE2 pattern; if native installation fails in the environment, record it as a blocker in the completion note rather than silently switching engines
